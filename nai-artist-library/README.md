# NAI 资料库

一个完全在本地运行的 NovelAI 绘图资料管理工具，用来整理画师串、场景提示词、评分和示例图片，替代越来越难维护的 Word 文档。

应用版本由后端 `/api/version` 返回，并与前端静态资源版本同步；更新时以源码中的 `APP_VERSION` 为准。

## 启动

双击：

```text
start.bat
```

程序会自动打开：

```text
http://127.0.0.1:5179
```

关闭启动窗口即可停止程序。程序只监听本机，资料和图片不会自动上传。

## 当前功能

### 画师串库

- 保存画师串名称、正向提示词和负向提示词。
- 支持 `0.5–5★` 半星评分和未评分状态。
- 按评分、名称、更新时间、使用次数或持久化的自定义顺序排序。
- 按评分区间筛选，并显示各区间数量。
- 每条画师串可以保存多张示例图。
- 选择任意示例图作为卡片封面。
- 收藏、置顶、搜索和批量管理。
- 独立的“负面提示词”目录。

### 场景提示词库

- 保存场景名称、正向提示词和负向提示词。
- 默认按中文标题拼音排序。
- 画师串库和场景库分别记住自己的目录、筛选、已加载卡片及浏览位置，来回切换时恢复离开处。
- 支持任意深度的树状目录。
- 目录可展开、折叠、新增、改名、移动、合并和删除。
- 可以直接拖动目录调整层级和顺序。
- 有下级目录时，直属卡片自动进入动态“未分类”。
- 自定义分组独立于目录，一张卡可以加入多个分组。
- 每个场景可以关联多张效果图并选择封面。
- 收藏、置顶、搜索和批量管理。

### 搜索与筛选

- 全库搜索可以选择全部字段、标题、正向提示词、负向提示词、标签或目录路径。
- 搜索结果高亮关键词，并标记命中的字段（包括“命中：路径”）。
- 默认搜索整个当前资料库，也可以切换为只搜索当前目录。
- 支持全部、有图、无图卡片筛选。
- 支持仅查看收藏。
- 搜索、目录、评分、图片和收藏筛选可以组合使用。

### 卡片与图片浏览

- 图片卡片、左图右文列表、等高无图卡片三种布局。
- 卡片布局支持每行 `3 / 4 / 5` 张。
- “使用次数”统计资料库复制和 dean-nai 替换操作，常用条目会自动排到前面。
- 选择“自定义排序”后可拖动卡片排序，也可用上下按钮在手机上调整；顺序保存在 SQLite 中。首次建立自定义顺序时，画师串以高评分优先，场景以收藏、使用和更新时间优先，不再按名称或数据库编号初始化。
- 横图、竖图、方图和其他比例都会完整显示，不裁切图片。
- 连续滚动分批加载卡片，不使用传统分页。
- 浏览时只加载缩略图，打开详情后才读取原图。
- 原图查看器支持多图前后切换。
- 可以删除误传的单张示例图，并清理无人引用的原图副本及缩略图；共享图片和外部关联原文件保留。
- 同一张图片可以同时用于画师串和场景卡片。

### 图片元数据

- 新上传的图片会自动读取内嵌生成参数。
- 旧图片第一次打开详情时按需读取，之后使用数据库缓存。
- 支持常见 PNG 文本块、NovelAI `Description/Comment`、NovelAI V4 角色 Prompt、WebUI 参数和 EXIF `UserComment`。
- 在原图详情中分别显示并复制：
  - 图片正向提示词
  - 图片负向提示词
  - 各角色提示词
  - Seed、Steps、采样器等生成参数
- 普通读取没有结果时，可以手动使用“深度读取”检查 PNG Alpha 隐写参数。

### 复制历史

- 点击卡片或详情按钮即可复制 Prompt。
- 顶部剪贴板图标保存最近 `50` 条复制记录。
- 场景和画师串共用复制历史。
- 历史只保存在当前浏览器，可以再次点击复制或手动清空。

### 编辑与批量操作

- 新建、编辑和删除资料。
- 新建资料后从当前浏览位置平滑移动到新卡片，不会先跳回页面顶部。
- 编辑已有资料后自动进入修改后的类型和分类，并移动到修改后的卡片位置。
- 一次上传多张示例图片。
- 可以关联一个本地图片文件夹，并在后台扫描和生成缩略图。
- 批量选择、全选当前结果、批量移动和批量删除。
- 批量删除需要二次确认。
- 页面提供回到顶部和回到底部按钮。
- 支持深色和浅色主题，并记住上次选择。

## 图片与数据位置

```text
data/library.db                 SQLite 数据库
data/media/nai/场景            场景原图
data/media/nai/画师串/名称     画师串原图
data/thumbs                    缩略图缓存
backups                        数据库、Word 和完整 ZIP 备份
output/audits                  图片审计报告
```

网页上传图片时，会在 `data/media` 中保存一份由程序管理的原图副本。原始上传文件不会被移动或删除。

关联本地文件夹时，程序只记录原图路径并生成缩略图，不会复制或移动该文件夹中的原图。

图片按照 SHA-256 去重。同一张图片关联多个卡片时，硬盘上只保存一份。

## 导出与备份

网页右上角“导出 / 备份”提供：

- 完整 JSON。
- 当前搜索和筛选结果的 Markdown。
- 画师串评分 CSV。
- 包含数据库、原图、缩略图和外部原图副本的完整 ZIP 备份。

删除卡片、批量删除或移除示例图时，自动永久清理不再被引用的原图副本和缩略图。同图被多张卡片使用时，等最后一个引用移除后再清理。通过“关联文件夹”引用的外部原文件不会被删除；本地画廊里的原文件、外置缓存及历史备份也不属于此清理范围。

历史无引用副本：进入“导出 / 备份 → 图片检查与空间清理”，先点击“检查可清理副本”，确认数量、占用空间和路径示例后执行统一清理。预览 30 分钟内有效；执行前重查引用和文件状态，不删除后来新增的引用或发生变化的文件。没有资产记录的散落图片只处理媒体目录中符合程序哈希命名且超过 10 分钟的文件，不处理无法确认归属的手工文件。失败文件会列出原因，可重新检查后重试。永久清理不进入 Windows 回收站。

## DOCX 与数据库转换

在网页的“导出 / 备份”中打开“Word 增量更新”，可以分别选择场景 DOCX 或画师串 DOCX。页面会先预览新增、修改、改名、保留、删除和匹配歧义；确认应用前会重新校验文件与数据库，并自动备份更新前的数据库。

增量更新默认不会删除 Word 中缺失的卡片。已有卡片会保留原 ID，因此目录、示例图、收藏、置顶、标签和自定义分组均会保留。只有主动勾选“同步删除”时，缺失卡片才会列入删除预览并要求二次确认。场景与画师串相互独立，画师串更新也不会改动“负面提示词”子目录。

勾选“同步删除”后，删除卡片同样会清理无引用图片副本。自动备份只有数据库快照，不包含图片；如需完整恢复，请先创建包含媒体的 ZIP 备份。

启动交互式转换工具：

```powershell
python docx_database_converter.py
```

也可以直接运行：

```powershell
python docx_database_converter.py export --database data/library.db
python docx_database_converter.py import --scenes "场景.docx" --artists "画师串.docx"
python docx_database_converter.py update --kind prompt --document "场景.docx" --preview-only
python docx_database_converter.py update --kind artist --document "画师串.docx"
```

导出的 Word 分为场景和画师串两个文件。Word 转数据库时，会在 `backups` 中生成新的数据库以及同版本的差异预览 JSON，列出：

- 新增
- 修改
- 未导入
- 内容不变
- 重名待复核

该简洁转换格式不包含图片、目录、收藏、标签、负面提示词和自定义分组。

## 图片一致性审计

桌面程序可直接进入“本地资料库 → 导出 / 备份 → 图片检查与空间清理”。点击“检查图片与提示词”后后台运行并显示进度，可选深度读取或忽略缓存。结果按问题类型分页显示，支持定位关联卡片和导出 JSON / Markdown 报告。提示词不匹配及角色词遗漏是启发式检查，仅提示人工核对，不会自动修改提示词或删除图片。

运行增量审计：

```powershell
python library_audit.py
```

它会检查：

- 原图路径失效。
- 缩略图缺失。
- 图片没有可读取的 Prompt。
- 图片 Prompt 与卡片提示词疑似不匹配。
- 图片包含角色 Prompt，但卡片中没有记录。
- 同一图片关联到至少三张卡片。

审计不会输出“没有图片的卡片”。默认只读取新增或发生变化的图片，其余直接复用缓存。

需要检查 PNG Alpha 隐写参数时运行：

```powershell
python library_audit.py --deep
```

深度模式需要解码图片像素，速度会比普通增量审计慢。

## Word 原始资料重新导入

重新读取项目中的 `nai.docx` 和 `nai提示词.docx`：

```powershell
python importer.py --all
```

需要清除并重新生成 Word 派生资料时：

```powershell
python importer.py --reset --all
```

`--reset` 不修改源 DOCX，但使用前仍建议先创建完整备份。
