# dean-nai

面向 Windows 个人本地使用的 NovelAI 生图与资料管理工作台。

它把生图、画师串与场景提示词资料库、可选外置资料接口、Danbooru 标签词库、本地画廊、在线画廊和生成统计整合在同一个项目中。项目不会把私人资料、生成图片或 NovelAI Token 上传到 Git。

> 本项目是非官方个人工具，与 NovelAI、Anlatan 或任何外置资料来源没有隶属、授权、认可或合作关系。公开版本不附带、推荐或代为获取任何外置资料及来源地址。

## 当前版本

本仓库提供 Windows 桌面应用源码。当前 GitHub Release 为源码预览，不包含预构建的 exe 或安装包；可以按下方“快速开始”在 Windows 10/11 上构建运行。

桌面版采用常驻工作区：切换生图、资料库、画廊和设置时，已经打开的页面不会反复卸载，因此输入内容、滚动位置和展开状态可以保留。

`dean-nai.exe` 是项目本地启动器，不是包含全部源码和数据的独立安装包。它会使用当前目录中的 `deanai/desktop-web-dist`、Python 源码和本地数据库。只从 Git 获取源码时，需要构建一次，因为 exe 和网页构建产物不进 Git；如果复制了完整的可运行目录，则通常可以沿用 exe，在新电脑安装 Python、后端依赖及 WebView2 运行环境即可。

## 主要功能

### 生图工作台

- 支持 NovelAI Diffusion V5 Full/Curated、V4.5 Full/Curated、V4 Full/Curated、Anime V3 和 Furry V3。
- 正向提示词拆分为“画师串 → 待用 → 场景提示词”，提交时按此顺序组合；负面提示词独立提交。
- V4/V4.5/V5 多角色提示词、角色负面词与位置控制；V5 支持最多 32 个角色栏位。
- 尺寸预设、自定义宽高、批量数、种子、步数、采样器、CFG、CFG Rescale、Noise Schedule、质量标签与负面预设。
- 不同模型分别记忆手动调整过的步数、CFG 等参数，切换模型后恢复对应模型上次使用值。
- V5 透明背景与 Straight Alpha 设置。
- Vibe Transfer、Director Reference，以及线稿、草图、去背景、清理、上色、表情修改、放大和增强等 Director 工具。
- 流式预览、批次进度、停止生成、失败提示、Anlas 估算、高消耗提醒和生成间隔保护。
- 资料库随机抽取支持目录多选、预设、评分/使用次数权重和最近结果避重。
- 抽卡模式可独立选择随机场景、随机画师串；默认只在成功后换词，不自动继续。自动模式支持范围间隔、周期休息、张数/时长/预计 Anlas 预算上限、倒计时及停止原因，每次一张，任何生成错误即停且不重试。
- 生图页顶部“额度”和设置页可查看 Anlas 余额、订阅/购买点数及 V5 免费额度百分比。两项有独立刷新按钮、更新时间、加载状态和错误提示，也可全部刷新；自动模式提交前核对最新额度，缺失或耗尽时不继续。
- V5 额度同时提供预估剩余张数：按满额约 1700 张、1024×1024 / 28 步 / 每次 1 张的脚本参考值换算，明确标注非官方估算，不代替真实额度校验。
- 可把当前画师串或场景提示词直接新增到本地资料库。

自动生成遇到额度未知、生成错误、达到张数/时长/预算上限时会停止，不会自动转为付费生成。

Token 输入支持显示/隐藏和清理后字符数提示；粘贴及保存时清理包裹引号、Bearer 前缀与空白，不截断 Token。桌面额度代理采用标准 urllib TLS 配置和真实客户端标识；实际账户查询需在本机验证。

额度查询若仍显示 Cloudflare 1010，表示请求受到站点访问策略限制，不是余额为零。程序会暂停本次会话的额度请求，并提供脱敏诊断复制。

### 生图页临时历史与内部回收站

生图页右侧历史保存在当前应用环境的 IndexedDB 中，与磁盘上的“本地画廊”不是同一套数据：

- 最多保留最新 100 张活动结果；生成新图后，超出部分只从临时历史中清理。
- 单张删除进入程序内部回收站，可以恢复；只保留最近 20 张，超出部分永久清除（包括升级前积累的旧记录），不影响磁盘画廊文件。
- “删除全部”会永久清空活动历史，不进入内部回收站。
- 上述操作不会删除已经下载或自动保存到磁盘的图片，也不会影响本地画廊索引。
- 放大查看支持滚轮/按钮缩放、拖动、适配视图、前后切换、下载、复制原图与复制无元数据 PNG。

### 本地提示词资料库

本地资料库由 Flask、SQLite 和原生前端组成，并嵌入桌面工作区：

- 画师串、场景提示词和独立负面提示词。
- 任意深度目录、目录展开折叠、移动、改名、合并、删除和自定义顺序。
- 自定义分组，一条资料可以同时属于多个分组。
- 全库或当前目录搜索；可选标题、正向、负向、标签、目录路径等字段。
- 收藏、置顶、评分、使用次数、有图/无图、分类、分组和多种排序组合筛选。
- 评分支持任意半星多选，生图资料库选择器与本地资料库一致；4 星和 5 星可一起选且不包含 4.5 星。
- 界面删卡/删除示例图先提交资料变更，再后台分批清理无引用原图副本；退出后未完成的队列可在下次启动继续。
- 卡片、图文列表、无图紧凑布局；缩略图延迟加载和原图详情。
- 新建、编辑、批量移动、批量删除、多图上传、本地文件夹关联和封面选择。
- 自动读取 NovelAI PNG、常见 PNG 文本块、EXIF、WebUI 参数、角色 Prompt；必要时可深度读取隐写元数据。
- 最近复制历史、使用次数统计，以及从资料库直接替换生图字段。
- 导出完整 JSON、当前结果 Markdown、画师评分 CSV，或创建包含数据库和本地媒体的完整 ZIP 备份。
- DOCX/Markdown 场景库和画师串库独立增量更新：先预览新增、修改、改名、歧义和删除，再确认应用并自动备份。
- 删除卡片、批量删除、移除示例图或增量同步删除卡片时，自动清理不再被引用的原图副本及缩略图；共享图片等最后一个引用移除后清理，外部关联原文件保留。
- “导出 / 备份 → 图片检查与空间清理”集成 `library_audit`：后台进度、六类检查结果、分页、定位卡片、JSON/Markdown 报告导出，以及历史无引用副本的统一清理。

详细的数据结构和转换命令见 [`nai-artist-library/README.md`](nai-artist-library/README.md)。

### 外置资料库

外置资料库是一个默认空白的通用接口。程序不内置任何第三方资料、专用网站适配器、来源地址或下载清单；用户只有在确认具备访问和使用权限后，才可自行填写 JSON、JSONL、CSV 地址，并配置条目数组路径、资源根地址和字段映射。

该接口不会抓取普通网页，也不会绕过登录、加密、付费墙、反爬或访问限制。项目不保证外部内容的可用性、准确性、许可状态或持续兼容性；用户自行配置的来源、缓存、备注和导入内容只保存在本地并由用户负责。

外置资料库可以：

- 更新全部或单个来源的文本索引。
- 只缓存缺失的压缩 WebP 缩略图；不会保存第三方原图。
- 按来源和左侧目录浏览、搜索、分页、收藏、置顶和写本机备注。
- 复制完整提示词；角色提示词会与主提示词一起保留。
- 全部写入场景提示词，或把主提示词写入场景、角色词分别写入角色栏位。
- 将条目连同提示词和可用缩略图加入或更新到本地资料库。

第三方内容和缓存位于被 Git 忽略的本地数据目录，不会随源码推送。

### 标签词库

- 索引本机 `tags/` 中的词库文件，并在生图主提示词、角色提示词和资料库搜索中提供英文标签/中文解释提示。
- 独立词库页面支持分类、搜索、分页、置顶和中文翻译修正。
- 点击标签可在“加入待用”和“复制为 `, tag, `”两种模式间切换。
- 支持按 Danbooru 标签 ID 增量同步全局标签，也可按作品标签补充特定范围。
- 可设置自动同步间隔；中文翻译保存在本机并可手动覆盖。

### 本地画廊

本地画廊读取你指定的磁盘目录，不复制原图：

- 支持多个目录、可选递归扫描、图片/视频扩展名配置和启动自动扫描。
- SQLite 增量索引、缩略图缓存、文件移动/重命名识别和 Prompt 全文搜索。
- 搜索空格分隔表示“或”，+词表示必须包含，-词表示排除，双引号用于完整词组。例如 cat dog +blue -text 表示包含 cat 或 dog，同时包含 blue 且不含 text。
- 支持输入页码跳转；详情左右按钮和对应快捷键可跨页连续浏览。
- 日期/日期范围、模型、采样器、方向、分辨率、步数和 CFG 组合筛选。
- 每页数量可在“设置 → 本地画廊”中调整，范围为 60–1000。
- 收藏、集合、隐私模糊、悬浮大图、双图对比和多选路径复制。
- 详情页可选择/复制提示词、复制原图、复制无元数据图片、只返回提示词或连同完整参数返回生图。
- 删除图片会移动到 Windows 回收站；详情页删除后自动顺位到下一张。

详情页快捷键均可在“设置 → 画廊快捷键”修改：

| 默认按键 | 操作 |
| --- | --- |
| `←` / `→` | 上一张 / 下一张 |
| `Esc` | 关闭详情 |
| `F` | 收藏 / 取消收藏 |
| `Delete` | 删除当前图片并顺位下一张 |
| `P` | 复制提示词 |
| `C` | 复制原图 |
| `J` | 复制无元数据图片 |
| `R` | 仅返回提示词 |
| `G` | 返回提示词与完整参数 |

### 在线画廊

- Danbooru、Safebooru、Gelbooru 和 AI TAG 独立适配。
- 搜索/最新、可用来源的日榜/周榜/月榜、分级筛选、随机浏览和分页。
- 本地黑名单、本地收藏、批量下载、复制标签、打开原图和带提示词返回生图。
- Gelbooru 账号参数可在设置中填写；其他公开查询不需要保存账号。

### 生成统计

- 生成成功即记为“生成”；首次下载或自动保存成功记为“留存”，重复下载同一结果不重复计算。
- 今日/累计生成与留存切换。
- 可选择日期范围的每日生成/留存堆叠柱状图。
- 活力热力图、小时分布、平均图片大小。
- 模型、采样器、画面比例和分辨率分布切换。
- 旧版本没有日期明细的累计数量会保留，但无法被准确还原到某一天。

### 设置

设置页包含：

- NovelAI Token 验证、账号与 Anlas 状态、请求重试次数和基础延迟。
- 自动保存、保存目录、文件名模板。
- 消耗警告、生成间隔和会员小图免费估算。
- 随机抽取、抽卡自动生成保护和生图资料库中的外置资料开关。
- 本地画廊目录和扫描规则。
- 本地画廊自定义快捷键。
- 在线画廊参数。
- 深色/浅色/跟随系统主题、五个可编辑强调色槽。
- 只有进入调整模式后才能拖动的左侧导航顺序。
- 便携资料包的完整与增量导出。
- 日志保留时间和打开本地数据/日志目录。

## 快速开始

### 从源码构建 Windows 桌面版

环境要求：

- Windows 10/11
- Python 3.11 或更新版本
- Node.js 22（与当前自动部署环境一致）
- NovelAI 图像生成功能可用的账号和 Persistent API Token

在项目根目录执行：

```powershell
python -m pip install -r nai-artist-library\requirements.txt
python -m pip install -r desktop_launcher\requirements.txt
cd deanai
npm ci
cd ..
powershell -ExecutionPolicy Bypass -File desktop_launcher\build-desktop.ps1
```

构建成功后会生成根目录 `dean-nai.exe`。运行时只监听 `127.0.0.1:5179`，不会自动开放给局域网。exe、构建产物、数据库和私人资料均被 `.gitignore` 排除。

### 浏览器开发模式

先安装资料库依赖，然后双击：

```text
start-local.bat
```

或运行：

```powershell
.\start-local.ps1
```

它会启动：

- dean-nai：<http://127.0.0.1:3000>
- 本地资料库：<http://127.0.0.1:5179>

关闭启动窗口或按 `Ctrl+C` 会停止两个服务。

### NovelAI Token

在“设置 → NovelAI 账号”填写以 `pst-` 开头的 Persistent API Token，并点击“验证并保存”。Token 保存在当前浏览器或桌面 WebView 的本地存储中，不写入源码和 SQLite 资料库。

不要把 Token 放进 `.env`、README、截图、日志或 Git 提交。

## 数据位置与删除规则

| 数据 | 位置 | 说明 |
| --- | --- | --- |
| 本地提示词资料库 | `nai-artist-library/data/library.db` | 卡片、目录、分组、评分、收藏、图片关联 |
| 资料库媒体 | `nai-artist-library/data/media/` | 程序管理的本地图片副本或关联信息 |
| 外置配置与缩略图 | `nai-artist-library/data/external-libraries/` | 来源配置、压缩缩略图；条目索引和用户备注在 `library.db` 中 |
| 本地画廊索引 | `nai-artist-library/data/local-gallery.db` | 只记录磁盘文件索引和元数据，不存原图 |
| 本地画廊缩略图 | `nai-artist-library/data/gallery-thumbnails/` | 可重新扫描生成的缓存 |
| 桌面浏览器状态 | `.desktop-webview/` | Token、主题、生图历史、统计账本、部分收藏和界面状态 |
| 日志 | `logs/YYYY-MM-DD/` | 默认保留 30 天，可在设置中修改 |
| 完整备份 | `nai-artist-library/backups/` | 手动创建的资料库 ZIP 和增量更新前快照 |

重要区别：

- 删除本地资料库卡片或示例图，会永久删除程序另外保存且无人引用的原图副本及缩略图；仍被其他卡片使用的图片保留。通过“关联文件夹”引用的外部原文件不删除。
- 删除本地画廊图片会把真实文件移到 Windows 回收站。
- 删除生图页临时历史只影响 IndexedDB，不影响磁盘本地画廊。
- 外置资料库只缓存缩略图，不下载第三方原图。
- 清理浏览器站点数据或 `.desktop-webview/` 会丢失 Token、界面设置、临时生图历史和部分本机收藏；重要图片应保存到磁盘，资料库应定期创建完整备份。

历史遗留副本可在“本地资料库 → 导出 / 备份 → 图片检查与空间清理”点击“检查可清理副本”，确认数量和空间后再清理。执行时重新核对文件与卡片引用，跳过检查后变化的文件。统一清理仅处理程序管理的媒体目录，保留外置库缓存、历史备份、外部关联原图和无法确认归属的手工文件；无资产记录的散落文件仅清理符合程序哈希命名且超过 10 分钟的文件。预览 30 分钟后失效。

资料库副本清理不进入 Windows 回收站。增量更新自动生成的是数据库快照，不包含已删除图片；如果需要以后完整恢复，请在操作前创建完整 ZIP 备份。

删除资料卡片或预览图时会异步清理无引用的应用内原图副本；外部原文件不受影响。

## 便携资料包

Windows 端进入“设置 → 便携资料”，可导出：

- 本地资料库全部
- 外置资料库全部
- 本地 + 外置全部
- 本地资料库增量
- 外置资料库增量

外置资料可勾选具体来源。完整包带有清单；增量导出需要选择上一次新版资料包作为比较基线。导出过程有进度和保存状态。

便携资料包是本地 JSON 文件，不会自动上传到 Git。

## 源码验证

前端位于 `deanai/`：

```powershell
cd deanai
npm ci
npm run typecheck
npm run build:desktop
```

后端与资料库测试：

```powershell
cd nai-artist-library
python -m unittest discover -s tests -v
```

仅重新构建桌面网页资源：

```powershell
cd deanai
npm run build:desktop
```

现有 `dean-nai.exe` 会读取新的 `desktop-web-dist`，所以只修改前端时通常不需要重新生成 exe。修改了 `desktop_launcher/launcher.py`、从源码首次安装，或要重新打包启动器时，再运行完整构建：

```powershell
powershell -ExecutionPolicy Bypass -File desktop_launcher\build-desktop.ps1
```

构建前应关闭正在运行的 `dean-nai.exe`，避免旧资源或文件占用干扰验证。普通源码编辑期间可以继续生图和新增资料，但涉及数据库迁移、后端数据结构或重新打包时，应先退出程序。
