# Security policy

## Supported versions

Only the latest published preview or stable release receives security fixes.

## Reporting

Use GitHub's private vulnerability reporting feature when it is available. Do not disclose tokens, private prompts, databases, logs, external source addresses, or other personal data in a public issue.

If a NovelAI token may have been exposed, revoke or replace it with the account provider before reporting the software defect. The project stores tokens locally and must never require a token in source code, a GitHub secret, or a diagnostic attachment.

## Scope

Reports should identify the affected version, operating system, reproduction steps, and the minimum redacted diagnostic information needed to understand the issue.
