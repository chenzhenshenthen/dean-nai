# Changelog

## v2.0.0-preview.1 - 2026-09-08

First curated public source preview based on the current Windows desktop version.

### Included

- NovelAI generation workspace with V5/V4/V3 model handling, account balance and V5 quota display.
- Local prompt library, optional user-configured external-library interface, vocabulary, local/online galleries, and generation statistics.
- Windows desktop launcher and reproducible frontend/backend development instructions.
- Portable full and incremental library package export.
- Local-library image viewer now returns to the previously visible card after closing.

### Not included

- User databases, images, prompts, external source addresses, tokens, logs, caches, or backups.
- A prebuilt Windows bundle. This preview is distributed as buildable source.
